TriangleOS

C · RISC-V · Virtual memory

Overview

A 64-bit RISC-V operating system written in C, with system calls, device drivers, threading, and a custom filesystem.

Kernel features

  • System calls and device drivers.
  • Threading, process scheduling, and exception handling.
  • Custom filesystem and Sv39 virtual memory paging.

Userspace support

Implemented exception handling, a process scheduler, and Sv39 virtual memory paging to support concurrent userspace execution.
