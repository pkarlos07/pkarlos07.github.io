Pipelined RV32I Processor

SystemVerilog · RTL · Verdi

Overview

A five-stage RISC-V processor designed in SystemVerilog, with branch prediction, hazard stalling, and memory support.

Design

  • Five-stage RV32I pipeline implemented in SystemVerilog.
  • Branch prediction and hazard stalling to handle control flow and instruction dependencies.
  • Memory support integrated into the processor pipeline.

Verification

Verified instruction execution using RVFI reference checks and debugged datapath behavior and pipeline timing in Verdi.
